  • Featured Project

    ECOTECH – Smart E-Waste Recycling System

    A smart sustainability system (App + Intelligent Bin) that connects IoT-enabled e-waste bins with an app to track electronic waste disposal in real time. Users are identified via CPF, earn points based on waste category and weight, and can view recycling history, analytics, and nearby collection points. We guarantee the profit by an Artificial Inteligence integrated in the Node.js API that analyses the picture captured by the bin's camera and the weight. The system processes sensor data, supports offline synchronization, and promotes responsible recycling through data-driven insights.

    Nexus Evolution Academy

    A full-stack online learning platform built to handle user authentication, paid courses, and automated communication in a production-ready environment. The platform combines a React frontend with a Java + Spring Boot backend, featuring JWT-based authentication, Stripe-powered payments, and transactional email automation via Brevo.

GenAI features were integrated to support intelligent platform capabilities and future personalization. The project reflects real-world backend engineering challenges, including secure auth flows, payment lifecycle management, and maintainable domain modeling.
