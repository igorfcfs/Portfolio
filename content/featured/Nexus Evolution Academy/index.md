A full-stack **online learning platform** built to handle user authentication, paid courses, and automated communication in a production-ready environment. The platform combines a React frontend with a **Java + Spring Boot** backend, featuring **JWT-based authentication**, Stripe-powered payments, and transactional email automation via Brevo.

The system was designed with scalability and security in mind, applying **REST API** best practices, clean architecture, and reliable payment workflows. **GenAI** features were integrated to support intelligent platform capabilities and future personalization. The project reflects real-world backend engineering challenges, including secure auth flows, payment lifecycle management, and maintainable domain modeling.
