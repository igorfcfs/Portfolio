**BioTech LIMS** é um sistema de alta performance para Gestão de Informações Laboratoriais (LIMS), desenvolvido especificamente para bioinformática clínica e pesquisa genômica. Criada como projeto final do CS50x de Harvard, esta aplicação web faz a ponte entre a gestão de dados biológicos e a engenharia de software moderna, oferecendo uma plataforma robusta para pesquisadores administrarem dados de pacientes, sequências genômicas e análises estruturais de proteínas.
