**BioTech LIMS** es un sistema de alto rendimiento para la Gestión de Información de Laboratorio (LIMS), desarrollado específicamente para bioinformática clínica e investigación genómica. Creada como proyecto final de CS50x de Harvard, esta aplicación web conecta la gestión de datos biológicos con la ingeniería de software moderna, ofreciendo una plataforma robusta para que los investigadores administren datos de pacientes, secuencias genómicas y análisis estructurales de proteínas.
