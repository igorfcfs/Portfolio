Comprehensive 3-module technical program focused on the analysis, design, development, testing, and deployment of computational systems. The curriculum emphasizes multi-platform development and industry-standard practices.

- **Core Curriculum:** Mastered **Algorithms & Programming Logic**, relational database modeling (MER/DER) and SQL implementation, and Object-Oriented Programming (OOP).
- **Web & Mobile Development:** Built responsive web applications using HTML, CSS, JavaScript, and PHP/Java, alongside native mobile Android development.
- **Engineering & Quality:** Learned **Systems Analysis** (Requirements, UML Diagramming), Interface Design (UI/UX principles), and Software Testing methodologies.
- **Capstone Project (TCC):** Developed and documented a complete software solution for a real-world problem, managing the project lifecycle from conception to deployment.
