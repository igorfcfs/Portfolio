Programa técnico integral de 3 módulos centrado en el análisis, diseño, desarrollo, prueba e implementación de sistemas computacionales. El plan de estudios enfatiza el desarrollo multiplataforma y las prácticas estándar de la industria.

- **Currículo Central:** Dominio de **Lógica de Programación & Algoritmos**, modelado de bases de datos relacionales (MER/DER) e implementación SQL, y Programación Orientada a Objetos (POO).
- **Desarrollo Web & Mobile:** Construcción de aplicaciones web responsivas usando HTML, CSS, JavaScript y PHP/Java, junto con desarrollo móvil nativo para Android.
- **Ingeniería & Calidad:** Aprendizaje de **Análisis de Sistemas** (Requisitos, Diagramación UML), Diseño de Interfaz (principios UI/UX) y metodologías de Pruebas de Software.
- **Proyecto Final (TCC):** Desarrollo y documentación de una solución de software completa para un problema real, gestionando el ciclo de vida del proyecto desde la concepción hasta la implementación.
