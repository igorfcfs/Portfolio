Programa técnico abrangente de 3 módulos focado na análise, design, desenvolvimento, teste e implantação de sistemas computacionais. O currículo enfatiza o desenvolvimento multiplataforma e práticas padrão da indústria.

- **Currículo Central:** Domínio de **Lógica de Programação & Algoritmos**, modelagem de banco de dados relacional (MER/DER), implementação SQL e Programação Orientada a Objetos (POO).
- **Desenvolvimento Web & Mobile:** Construção de aplicações web responsivas usando HTML, CSS, JavaScript e PHP/Java, juntamente com desenvolvimento mobile nativo para Android.
- **Engenharia & Qualidade:** Aprendizado de **Análise de Sistemas** (Requisitos, Diagramação UML), Design de Interface (princípios UI/UX) e metodologias de Teste de Software.
- **Projeto de Conclusão (TCC):** Desenvolvimento e documentação de uma solução de software completa para um problema real, gerenciando o ciclo de vida do projeto desde a concepção até a implantação.
